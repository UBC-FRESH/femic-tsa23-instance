TSA23 FEMIC Instance
====================

A standalone instance of the FEMIC forest estate model for TSA23 (100 Mile House,
British Columbia): source layers, inventory, silviculture, the Patchworks export, and
the WS4 build and simulation.

This site is the RTFM surface for the project. Agents read the relevant page before they
act, and cite it in their reports. Start with the repository's ``AGENTS.md`` and
``ROADMAP.md``; the operator runbooks live in ``runbooks/`` and the measured evidence
behind each number lives in ``planning/``.
